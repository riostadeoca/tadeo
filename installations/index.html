Trouble loading this piece?

This installation is built with 3D graphics that need your browser's hardware (or "graphics") acceleration turned on. It's on by default in most browsers — if this piece won't load, that setting has probably been switched off.

How to turn it on
  • Chrome / Edge — go to Settings → System, turn on "Use graphics acceleration when available," then relaunch the browser.
  • Firefox — go to Settings → General, scroll to Performance, uncheck "Use recommended performance settings," then check "Use hardware acceleration when available."
  • Safari — this is on by default and rarely needs changing.
